# Estudos para a Maratona de Programação Paralela

## Descrição

Projeto de ensino para estimular o uso de ferramentas de Processamento de Alto Desempenho (PAD) e preparar estudantes para maratonas de programação paralela (SBAC-PAD/WSCAD/ERAD-RS), reduzindo dificuldades de programação por meio do estudo colaborativo.
