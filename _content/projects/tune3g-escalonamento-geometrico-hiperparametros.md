# Tune3-G: Escalonamento Geométrico de Hiperparâmetros para Redes Neurais em Cibersegurança

## Descrição

Framework de otimização que usa matemática avançada para ensinar redes neurais a se autoajustarem durante o treinamento, tornando sistemas de detecção de malware mais rápidos, estáveis e confiáveis, com tecnologia disponibilizada como software livre.
